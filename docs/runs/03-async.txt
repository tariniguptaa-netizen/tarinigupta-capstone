FastAPI handles async endpoints using Python's `async` and `await` syntax, allowing for non-blocking I/O operations. When you define an endpoint with `async def`, FastAPI treats it as an asynchronous function. This enables the server to handle multiple requests concurrently without waiting for each request to complete before starting the next one.

Here's a basic example:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    # Simulate an asynchronous operation (e.g., database query)
    await some_async_function()
    return {"item_id": item_id}
```

In this example, `some_async_function()` could be an I/O-bound operation, such as fetching data from a database or an external API. FastAPI uses an ASGI server (like Uvicorn) to manage these async operations efficiently, allowing for high concurrency and better performance in handling requests.
